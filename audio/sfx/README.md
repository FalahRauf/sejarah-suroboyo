# Efek Suara Sendiri (opsional)

Taruh file **.mp3** di folder ini dengan nama persis seperti di bawah. Game otomatis memakai file itu.
Kalau filenya tidak ada, game tetap memakai suara sintesis bawaan.

| File | Dipakai untuk |
|---|---|
| rifle.mp3 | Tembakan senapan pemain |
| shot.mp3 | Tembakan musuh / pejuang dari kejauhan |
| boom.mp3 | Ledakan (granat, meriam, bom) |
| reload.mp3 | Mengisi peluru |
| step.mp3 | Langkah kaki |
| hurt.mp3 | Pemain terkena tembakan |
| cheer.mp3 | Sorakan warga "Merdeka!" |
| grenade.mp3 | Mencabut pin granat |
| door.mp3 | Membuka / menutup pintu |
| whistle.mp3 | Siulan peluru meriam yang jatuh |

Sumber efek suara gratis: freesound.org, pixabay.com/sound-effects, atau rekam sendiri.
Pastikan lisensinya boleh dipakai, lalu cantumkan sumbernya di halaman Kredit (`index.html`, bagian `#credits`).

Catatan: efek suara dari file hanya jalan saat game dibuka lewat server/website (misalnya Vercel atau Live Server),
tidak saat file `index.html` dibuka langsung dengan klik dua kali.
